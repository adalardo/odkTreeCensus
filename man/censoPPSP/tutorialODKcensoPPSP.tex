\section{Coleta de dados por dispositivo móvel}
\label{sec:coleta_de_dados_por_dispositivo_movel}


\href{https://opendatakit.org/}{Open Data Kit} é um projeto colaborativo de código aberto para coleta, armazenamento e gerenciamento de dados. A proposta é disponibilizar instrumentação de baixo custo para coleta de dados que possa ser utilizada em áreas remotas e sem infraestrutura de internet. Permite a coleta de dados tanto online quanto offline e tem a possibilidade de descarregar dados quando se conecta a alguma rede de internet.

Desenvolvemos um formulário, baseado nessa plataforma, para fazer o censo da Parcela Permanente da Ilha do Cardoso, agora atualizado para coleta de dados de árvores em parcelas. 
Para ter mais controle sobre o processo, decidimos usar apenas a interface de coleta de dados, chamada \textbf{ODK Collect} e não todo o ecossistema OKD. Para utilizá-lo é preciso instalar o \textbf{ODK Collect} através da \textbf{Play Store} em dispositivo móvel Android, de preferência um tablet, mas um smartphone dá conta do recado. Nossos testes utilizaram a versão do \textbf{ODK Collect v2024.2.4 e v2024.3.3}, como o projeto tem ido em uma rota de limitar o uso das ferramentas sem a conexão com todo o ecossistema, caso seja necessário é possível instalar versões antigas do app, utilizando o arquivo \textit{apk}, como o do link abaixo:

\url{https://github.com/getodk/collect/releases/tag/v2024.3.3}


Depois de instalado é necessário inserir os arquivos de formulários e dados do censo anterior da parcela no dispositivo para ativar o formulário.

\subsection{Preparando o dispositivo móvel}
\label{sec:preparando_o_dispositivo_movel}

O \href{https://opendatakit.org/}{Open Data Kit} tem um mecanismo próprio para instalar formulários e retornar os dados coletados, chamado \textbf{ODK Central} que precisa estar instalado em um servidor para se comunicar com o \textbf{ODK Collect}. Uma possibilidade é usar o \textbf{ODK Cloud}, um serviço de núvem do ODK  com o Central instalado, uma pechincha de USD\$250.00 por mês... Não temos ainda o \textbf{ODK Central} instalado em nosso servidor, por isso iremos usar ``força bruta'' para instalar os formulário e extrair os dados do aplicativo móvel. Antes precisamos criar um projeto no  app \textbf{ODK Collect}. 

\subsubsection{Criando um projeto ODK Collect}

Entre no aplicativo \textbf{ODK Collect} e siga os passos solicitado para criar um novo projeto inserindo os dados diretamente no app selecionando a opção \textbf{Entrar com os detalhes do projeto manualmente} (Figura~\ref{fig:criaODK} a).
Além de um usuário e senha, que precisam ser criados, há a necessidade de incluir uma url para a conexão com o \textbf{ODK Central}. Aqui podemos incluir o endereço que pretendemos instalar o \textbf{ODK Central} futuramente (http://odk.ib.usp.br). Não se preocupe com nenhum desses dados iniciais, apenas crie o projeto e preencha os campos solicitados (Figura~\ref{fig:criaODK} b). Caso seja solicitado permita que o ODK Collect emita notificações no seu dispositivo móvel (Figura~\ref{fig:criaODK} c) 

Para incluir o formulário no \textbf{ODK Collect} precisamos de um projeto criado no app e acesso à memoria interna do dispositivo Android com permissão para edição das pastas do \textbf{ODK Collect}.

\subsubsection{Acessando as pastas do ODK Collect}


Para utilizarmos o \textbf{ODK Collect} sem conexão com o \textbf{ODK Central} é necessário ter acesso à memória interna do dispositivo móvel android. Garanta que seu dispositivo permite o acesso a essas pastas quando conectado a um computador. Caso tenha problema em acessar a memoria interna do dispositivo androide veja o tutorial:

\url{https://pt.wikihow.com/Acessar-um-Celular-Android-pelo-Computador} 

Ao iniciar um projeto no \textbf{ODKCollect} uma pasta será criada na memória de \textbf{Armazenamento interno} do dispositivo. Essa pasta estará em um caminho similar a:\\

\textbf{''/Android/data/org.odk.collect.android/files/projects/''}\\

Esse caminho pode ser diferente dependendo da versão do Android e do \textbf{ODK Collect}. O diretório do projeto criado neste caminho terá como nome de pasta um código, similar a ``\textit{f00742c6-b995-48bd-8b7b-9fd8ef493a8d}''.  Conecte o dispositivo móvel em um computador e navegue até a pasta do projeto criado e verifique se contém ao menos as seguintes subpastas:

\begin{itemize}
\item instances
\item forms
\item metadata
\item layer
\end{itemize}




Vamos copiar os formulários e arquivos de media na pasta  \textbf{forms}, caso a pasta não exista é necessário criá-la.

\subsubsection{Localidade da Parcela}

Selecione a parcela em que o censo está ocorrendo. Caso seja uma parcela que não as do PPSP, selecione a opção \textit{Parcela não cadastrada} e em seguida forneça o nome ou código da parcela (Figura~\ref{fig:local}). Além disso, forneça as seguintes informações:
\begin{itemize}
\item{Número de digitos das placas}: o número de dígitos devera compreender apenas os dígtios variáveis, códigos fixo para o censo devem ser desperezados (p.ex: '25' ao início para indicar o ano da coleta de dados)
\item{Menor e Maior valor de placa nova}: aqui deve-se restringir ao máximo os valores das placas, indicando a sequência de placas que estão sendo levandas a campo no dia de trabalho, o aplicativo não permitira a entrada de valores diferentes do que foi definido nesta parte. Como padrão de valores estão os limites de numeração das placas que foram feitas para o censo de 2025
\item{A unidade de trabalho em campo}: aqui indique o tamanho do subquadrat que representa a unidade de trabalho, por enquanto só temos implementado a unidades de 10x10 ou 5x5m
\item{Diâmetro de inclusão}: confira se o diâmetro mínimo de inclusão da parcela está correta, não será possível entrar valores menores que esse, a menos que seja checado e justificado
\end{itemize}

\subsubsection{Árvores}
\label{sec:arvores}


As informações coletadas para cada árvores, em parte, depende de algumas condições, a principal delas é a presença ou não da placa e se o indivíduo está ou não morto. A primeira seleção ao iniciar a coleta de dados de uma árvore é definir esses estados, como mostra a Figura~\ref{fig:treeStart}a.

Caso a árvore já esteja plaqueada é preciso indicar o número da placa. A primeira página da árvore do tipo \underline{\textit{plaqueada}} apresenta os números de placa que estavam presentes nessa mesma unidade de trabalho no censo anterior. Caso o número não esteja nessa lista, siga para a página seguinte que apresenta todos os números de placas do censo anterior na localidade. Por fim, se o número ainda não estiver listado siga para a página que permite a inclusão do número de placa antigo que não esteja listada.  Nessa páginas é listada também o números que já foram anotados em {\underline{Árvores já anotadas:}}, para evitar que o mesmo número seja anotado mais de uma vez. 

Na página seguinte é preciso responder se \textit{\underline{A placa está em boas condições?}}. Verifique se a placa está legível e bem fixadas, caso contrário anote \textbf{\underline{não}} e siga para os próximos passos que inclui a  troca da placa por um novo número (Figura~\ref{fig:treeStart}d).
Nessa página é possível também tirar uma foto ou escolher uma imagem do dispositivo, aqui é desejável que seja \textcolor{Cyan}{fotografada a nova placa fixa na árvore junto com a antiga, para eventuais checagens}.

\subsubsection{Altura }
\label{sec:altura_e_tipo_de_medida}


A página de coleta de altura da árvore apresenta duas escalas. Na primeira e utilizada \textit{\underline{se a altura é até 10m}}. Nesta escala é possível selecionar valores entre 1.5 m até 10 m em intervalos de 0.5. Na barra de seleção \textit{\underline{se a altura é mais de 10m}} a escala tem intervalos de 1m. Não é possível incluir valores em ambas as escalas, caso necessário remova a resposta clicando no valor até aparecer a janela com a opção de \textit{Remover a resposta}. 

Caso a altura seja menor ou muito maior do que o valor anotado no censo anterior, aparecerá a informação que há inconsistência no valor e será solicitado  a equipe coletar novamente a altura da árvore. Em seguida será solicitado que a equipe indique o motivo da inconsistência e confirme o novo valor coletado.

\subsubsection{Medida de DAP ou PAP}
\label{sec:medida_de_dap_ou_pap}


A medida do diâmetro ou perímetro é tomado a 1,3 m do solo (altura do peito) o ponto de medida padrão. Entretanto, há três tipos básicos de medidas possíveis, duas associadas ao DAP (diâmetro a altura do peito) e uma associada ao PAP (perímetro a altura do peito), por isso a primeira fase da medida de DAP/PAP é selecionar o \textit{\underline{tipo de medida}} (Figura~\ref{fig:papDap} a):


\begin{itemize}
  \item \textbf{\underline{DAP com paquímetro}}: árvores pequenas, com menos de 5 cm (50 mm) de diâmetro \textbf{devem} ser medidas com paquímetro. O aplicativo permite que até diâmetros de 8 cm sejam medidos com paquímetro, diâmetros maiores devem necessariamente ser medidos com outro método. A medida aqui é feita em \textbf{mm} inteiros, sem casas decimais (Figura~\ref{fig:papDap} b).
\end{itemize}

\begin{itemize}
  \item \textbf{\underline{DAP com fita diamétrica}}: um tipo especial de fita cuja escala retorna o diâmetro associado ao perímetro medido, ou seja uma fita com escala de $\pi$ cm.  
\end{itemize}

\begin{itemize}
  \item \textbf{\underline{PAP com fita métrica}}: fita métrica normal, que mede o perímetro da árvores (cm).  
\end{itemize}



%\includegraphics[keepaspectratio=true,width=0.8\textwidth]{odkDAP}

Meça o diâmetro ou perímetro conforme o método de medida definido. Lembre-se que as escalas podem estar em \emph{cm} ou \emph{mm}, verifique se está anotando na escala correta. 

Caso haja discrepância na medida de DAP/PAP com relação ao censo anterior será solicitado à equipe que refaça a medida, indique possíveis causas da discrepância e confirme a nova medida (Figura~\ref{fig:papDap} c e d) ,  semelhante ao que foi feito com discrepâncias na medida de altura.

Ao final responda à pergunta  \textbf{\underline{Árvore com um fuste?}} (tronco principal). Anote \textbf{\underline{não}} se a árvores tiver mais de um fuste (tronco) principal.
