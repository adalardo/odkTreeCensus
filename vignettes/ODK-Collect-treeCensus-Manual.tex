    \textsc{Contexto}\par

    \vspace{.5cm}
Coleta de dados em campo apesar de gerarem muita informação, tem fontes de incertezas e erros envolvidas no próprio procedimento de aquisição da informação. Inventários florestais apresentam várias fontes de erro associada a aquisição da informação, entre as mais importantes estão: anotação errada em campo e transcrição dos dados de papel para o formato digital. Esses erros são custosos para serem resolvidos pois, muitas vezes, demandam o retorno a campo e retomada da medida, além de poderem comprometer as conclusões dos trabalhos científicos. Com o intuito de minimizar erros e agilizar o procedimento de coleta de dados de inventários florestais produzimos um aplicativo para dispositivo móvel que minimiza a entrada de dados com discrepâncias e elimina a fase de transcrição de dados anotados em papel para o formato digital. Acoplado a esse aplicativo desenvolvemos um conjunto de ferramentas assessorias para o processamento, checagem e gestão dos dados. Este documento está focado na fase de coleta de dados utilizando o aplicativo ODK-Colect e o formulário censoPPSP2025.
