Após conectar o tablet ao computador abra as notificações e nas opções
de conexão USB selecione a ``Transferir arquivos/Android Auto''.
Mantenha o dispositivo ativo e sem bloqueio de tela.

\subsection{Configurando o USB
Padrão}\label{configurando-o-usb-padruxe3o}

Para tornar o dispositivo android sempre configurado para a troca de
arquivos pelo usb, conecte ao computador, vá para: * Configurações *
Opcções do desenvolvedor * Configurações USB padrão * selecione:
``Transferindo arquivos/Android Auto'' * desconecte o cabo USB e
reconecte * confira a Configuração USB padrão * caso mude para ``Apenas
carregar o tablet'' * selecione novamente ``Tranferindo arquivos/Android
Auto'' * desconecte e reconecte o cabo USB para verificar se a
configuração permanece.

\texttt{ODK\ Central} instalado.

\subsection{Atualizar o formulário
xml}\label{atualizar-o-formuluxe1rio-xml}

formato xml utilizando o pacote do python pyxform. O pyxform foi
incorporado no pacote do R, assim como o \texttt{treeCensusForm.xlsx} e
o \texttt{treeCensusForm.xml}.
