    \vspace{.5cm}
O procedimento de coleta de dados em campo tem fontes de incertezas e erros envolvidas na de aquisição da informação. Entre as fonte de erro mais importantes nos inventários florestais estão: erros na anotação do dado e transcrição da informação em papel para o formato digital. Esses erros são custosos para serem resolvidos, muitas vezes demandando o retorno à campo, o que nem sempre é possível. Evitar fontes de erros no procedimento científico é essencial para não comprometer as conclusões dos trabalhos científicos. O pacote \textbf{odkTreeCensus} tem como objetivos minimizar a entrada de dados com discrepâncias durante a aquisição da informação e eliminar a fase de transcrição de dados anotados em papel. O pacote auxilia na construção e gerenciamento de formulários de entrada de dados para o aplicativo ODK-Collect, criando os arquivos necessários e gerenciando a entrada e saída de dados.

formato xml utilizando o pacote do python pyxform. O pyxform foi
